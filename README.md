# Previsão do Tempo

🔗 **Site ao vivo:** https://isac-ribeiro.github.io/projeto-ajax/

Consulta de clima por cidade ou região, usando a API gratuita
[Open-Meteo](https://open-meteo.com/). Mostra condições atuais,
chance de chuva com horário previsto e previsão dos próximos 5 dias.

## Funcionalidades

- Busca por cidade ou região, com sugestões de locais próximos
- Temperatura atual, sensação térmica, vento e descrição do tempo
- Chance de chuva com horário previsto (quando aplicável)
- Previsão dos próximos 5 dias
- Atalhos para capitais brasileiras
- Abas "Buscar Clima" e "Ajuda / Sobre"
